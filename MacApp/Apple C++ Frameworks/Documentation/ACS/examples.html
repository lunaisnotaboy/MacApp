ACS Examples

Allocator

Allocator is a port of Ali Ozer's Core Foundation example application to ACS. It has been changed to use CCFString and CCFData, but the allocator functions themselves are still using the CF APIs.

Dictionary

Dictionary is a port of Ali Ozer's Core Foundation example application to ACS. It uses CCFString, CCFData, CCFDictionary, CCFArray, CCFNumber and CCFPropertyList.

EHTest

EHTest is a test application originally written by Mark of the Unicorn, placed in the public domain, and included in the publicly available STLPort package. EHTest was changed to work with the Metrowerks Standard Library, and all the tests were turned off except for the string test. A new test was made to exercise FTLString, based on the Standard Library string test. The insertion test framework was fixed to generate non-zero random numbers.

More tests will be added back into EHTest as the corresponding FTL classes are implemented.

Preferences

Preferences is a port of Ali Ozer's Core Foundation example application to ACS. It has been made to build with ACS, but the Core Foundation calls haven't been changed to their ACS equivalents yet.

String

String is a port of Ali Ozer's Core Foundation example application to ACS. It uses CCFString and CCFData, and shows off several features of CCFString.
