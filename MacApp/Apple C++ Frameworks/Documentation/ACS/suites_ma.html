ACS Suites

This page describes all of the ACS suites, including the older class suites that are included with MacApp in order to insure compatibility. As of Release XV, there is also a standalone ACS that contains a focused subset of the class suites.

Appearance

A suite which provided high-level abstractions required for supporting Apple's Platinum Appearance. It also provides support for presenting a Platinum appearance even on Macintosh systems lacking the Appearance Manager.

Containers

A suite providing a variety of containers such as lists and dynamic arrays based on the earlier MacApp classes providing the same functionality.

Core

A suite of 'core' abstractions and classes at a relatively lower-level. This includes our exception classes, auto-pointers, general purpose types, auto-switches, etc.

Files

This suite contains classes representing files, file specs, etc. based on the earlier MacApp classes providing the same functionality.

Foundation

The Foundation suite provides C++ interfaces for CoreFoundation.

FTL

The FTL suite provides a bridge between CoreFoundation and the C++ standard library. The FTL interfaces are compatible with the C++ standard library, but the implementation is based on the Foundation suite.

Help

Support classes for Apple Guide.

Imaging

This suite contains classes representing common geometric entities such as points, rects, and regions. Many of these classes are based on the MacApp geometry and imaging utilities and classes including CRGBColor_AC and CGDIterator_AC.

Java

Support classes for working with embedded Java applets.

Memory

A fast memory allocator for use on systems before Mac OS X.

Patterns

This suite contains many 'pattern' classes which implement strategies such as described in Design Patterns by Gamma, et al.

QuickTime

 If you're working with QuickTime, especially QT atom containers, you will find a new QuickTime suite in ACS that is really slick It will definitely make your life easier.

Streams

A suite of classes implementing various stream classes, derived from earlier MacApp classes providing similar functionality.

Text

This is a very small suite which currently contains a text parser class.

Threads

Another major suite of classes which provide a simple, Java-like thread implementation which supports both cooperative and MP threads.

TidyHeap

An important support suite which contains classes which provide a variety of allocation and memory protection tools. Read the excellent MacTech article on TidyHeap.

Toolbox

This suite contains a set of classes which generally represent key portions of the Macintosh toolbox such as the clipboard. This suite is currently undergoing major revision.
