Imaging

This suite contains classes representing common geometric entities such as points, rects, and regions. Many of these classes are based on the MacApp geometry and imaging utilities and classes including CRGBColor and CGDIterator.

CPattern_AC

CPattern_AC is a new utility class that wraps the toolbox's Pattern structure; CPattern_AC IS-A Pattern. The interface and implementation for CPattern_AC can be found in:

 

:ACS:Suites:imaging:includes:CPattern_AC.h

:ACS:Suites:imaging:sources:CPattern_AC.cpp

This class was formerly known as Patterns_AC.

Standard system patterns, which could formerly be accessed directly via the QuickDraw globals, can now be acquired using a number of static functions in CPattern_AC. This includes:

 

White(),

Gray(),

LightGray(),

DarkGray(), and

Black().

To acquire the qd.gray pattern, for example, you should use something like:

 

::PenPat(CPattern_AC::Gray());

Added Carbon-style glue functions in CPattern_AC and ImagingUtils_AC so developers can start using them even before they have the Carbon headers.
