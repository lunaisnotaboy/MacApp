Don't Use CPascalStr_AC Directly

One of our developers had some trouble using:

CStream_AC::ReadString(CPascalStr_AC&, short) { ... }

because CPascalStr_AC does not implement the assignment operator. To fix this we recommend that the function above be replaced with:

template <typename T>

void ReadString(TemplatePascalStr<T>& newString,

short maxSize) { newString = ReadString(maxSize); }

and then eliminate the CStr255_AC optimization, using a typedef for CStr255_AC as for the other string lengths instead.

Also, it would be a good idea to declare assignment operators for CPascalStr_AC as private so that any inadvertant asignments can be detected by the compiler.
