WASTE

WASTE support is built into MacApp. There is no need to perform any special installation.

What is WASTE?

WASTE is a TextEdit replacement written by Marco Piovanelli. WASTE stands for WorldScript-Aware Styled Text Engine. The main features of WASTE are:

  • Compatible with styled TextEdit.
  • Text size is limited only by memory (no 32k barrier).
  • Full WorldScript support, including inline input and bidirectional scripts.
  • Built-in support for undo.
  • Drag and drop text editing.
  • Embedded objects.
  • Real tabs.
  • Fully justified text.
  • Support for Internet Config
  • Customizable low-level hooks for drawing, measuring text, and more.

Additional information can be found at Macro Piovanelli's Main WASTE Page.

Changes and Enhancements

Carbon

The version of WASTE 1.3 has been carbonized.

Stylers

Support for WASTE Stylers has been added to the WASTE library. Stylers add behavior to text styles. A styler can draw and receive mouse clicks. The Bowser example uses a styler to implement URL links.
