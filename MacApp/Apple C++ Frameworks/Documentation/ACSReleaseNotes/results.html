Release XV.I Build Notes

The various example applications included as part of the ACS distribution have been built with both Apple's Project Builder (running under Mac OS X) and Metrowerks' CodeWarrior (running under Mac OS 9.1). Each of the examples were then run on both Mac OS 9.1 and Mac OS X with the exception of the examples built with Project Builder that were run only under Mac OS X.
