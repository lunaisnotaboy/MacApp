Release XV.I

The emphasis for MacApp Release XV is to support building robust applications for Mac OS X as well as for Mac OS 8 and 9.

Very few modifications to existing MacApp applications will be required when moving from MacApp Release 14 to MacApp Release XV. We hope you will use it and give us feedback on how it meets your needs; the best way to contact us is to send e-mail. Also, let us know what features you would like to see in future versions of the Apple C++ Frameworks.

Release XV.I is a maintenance release of XV. It includes bug fixes and support for CodeWarrior Pro 7.

Features

Project Builder

Support for building Mach-O executables in Project Builder, on Mac OS X.

Mac Toolbox

The framework now can use Carbon Events instead of the traditional main event loop.

A new ACS suite with C++ APIs for Core Foundation. The beginning of another new suite that allows Core Foundation containers to interoperate with the C++ standard library.

A new ACS class, CWindow_AC, for working with toolbox windows.

C++ Standards

Support for using standard strings in conjunction with pascal strings. Utilization of standard strings in the framework.

Apple Class Suites

ACS now can be installed and used by itself, without MacApp.

The ACS examples demonstrate using ACS by itself, and also using ACS in conjunction with PowerPlant.

Miscellaneous

Many other fixes, enhancements, and improvements.
