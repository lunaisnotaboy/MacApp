Targets

MacApp-based applications can currently be built for two supported platforms: Mac OS 8/9 and Mac OS X/Carbon. While MacApp can be compiled and linked for Microsoft's Windows OS this work has not been completed.

Mac OS 8/9

Support for building MacApp-based applications for use on Mac OS 8 and Mac OS 9 is quite mature and reliable. The minimum requirement is Mac OS 8.1 and the Appearance Manager. CodeWarrior projects are supplied for building 68K and PowerPC, and debug and non-debug 'flavors' of the libraries and examples.

Mac OS 9/X CFM

MacApp includes support for building MacApp-based applications which can run under Mac OS X as well as CarbonLib on Mac OS 9. All but three of the MacApp example applications build and run for Mac OS X; all build and run on Carbon under Mac OS 9. CodeWarrior projects are supplied for building Carbon debug and non-debug flavors of the libraries and the examples.

Mac OS X Mach-O

MacApp includes support for building Mach-O executables in Project Builder on Mac OS X.
