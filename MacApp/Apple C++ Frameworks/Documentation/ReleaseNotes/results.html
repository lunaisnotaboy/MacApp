Release XV.I Build Notes

The various example applications included as part of the MacApp distribution have been built with both Apple's Project Builder (running under Mac OS X) and Metrowerks' CodeWarrior (running under Mac OS 9.1). Each of the examples were then run on both Mac OS 9.1 and Mac OS X with the exception of the examples built with Project Builder that were run only under Mac OS X.

General Comments

Do not turn on 'Help regions' in 'Debug Flags' window or a bad address exception will get thrown.

A -20005 exception will be reported if a printer has not been selected for PPC and 68K debug builds.

Under Mac OS X a 'Quit' menu item appears under the File menu as well as under the application menu. This occurs because the various example resources have not been customized for Carbon at time time.
