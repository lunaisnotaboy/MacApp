Network Examples

DemoHTTPClient

DemoHTTPClient is a simple HTTP client based on the OTSimpleDownloadHTTP sample application from DTS. CDownloadSample is a CCooperativeThread_AC that calls the DownloadURL function. DownloadURL parses the URL into a host name and file name, and calls SimpleHTTPDownload. SimpleHTTPDownload uses a CTCPEndpoint to connect to the host, send the HTTP command, and receive the requested file.

DemoHTTPServer

CHTTPListenerThread and CHTTPServerThread implement an HTTP server on the Network server framework. The logic is based on the OTSimpleServerHTTP sample application from DTS.
