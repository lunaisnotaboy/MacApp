About Network

Network is version 2.0 of the MacApp Network framework. It is simpler, easier to use, and provides more built-in functionality for creating internet client applications.

Features

The foundation of Network is the TCP/IP connection class. The connection class requires Open Transport (1.1 or later) and the Thread Manager. It also comes with a text buffer class and a text pointer class that works with the text buffer.

The initial version of Network includes sample applications that do Ping, a simple HTTP client, a simple HTTP server, and a terminal (not quite Telnet). Future versions of Network may include support for parsing and more protocols.

Requirements and Limitations

The Open Transport APIs that Network uses are the client APIs that will be supported in Carbon. Network uses Open Transport in synchronous blocking mode, which requires the use of threads. Synchronous blocking mode is much simpler and more robust compared to asynchronous callbacks. The programming model it provides is much more like the way network programming is done on other operating systems such as Unix and Windows. The disadvantage of synchronous blocking mode is that it doesn't provide the maximum possible performance on MacOS 8.x, because it gives time to other applications even during network I/O. If you are writing the Finder, or developing a dedicated server that runs only on MacOS 8.x, you probably should write your own optimized network connection code. Network should be good for the vast majority of network clients and for simple servers.

Network is primarily for internet applications, and supports protocols that are based on TCP/IP and, to a lesser extent, UDP. Because it uses Open Transport, theoretically Network could support other communications protocols such as AppleTalk, raw ethernet, or direct serial connections, but developers who want to do that are on their own.

Network requires MacApp & ACS Release 14 or later.
