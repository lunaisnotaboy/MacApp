Project Builder Support for the ACS Examples


The "ACS Tool" folder is Project Builder stationery for creating a simple ACS C++ tool. To install it, copy it to:

    /Developer/ProjectBuilder Extras/Project Templates/Tool/

To use the ACS Tool project stationery, simply choose it in the New Project Assistant in Project Builder, then replace "main.cpp" with your own sources and build. The project has relative paths so it will work if it is next to the other ACS example projects. If you move it to a different location, you will need to fix up the relative paths in the Files panel and the Build Settings.

Have fun!
