TidyHeap Change History:

TidyHeap ----- R13u3 -----

Changes

  1. Rewrote the double delete checking so that it can be left on constantly. This uses a hash table to keep track of currently allocated blocks. A new file is written called MyApp.stt which logs some information used by the double delete mechanism to allow the double delete tracking to tune itself to the client application. This option is now on by default.
  2. Added the option for TidyHeap to create all its internal memory in temporary memory. This option is now on by default.
  3. Changed format of .prf file.
  4. Added new method 'PrintDebugString' in preparation of Windoze version.
  5. Added some extra information that is logged to the logger at termination time. This is optional.
  6. Removed CActionDoubleDeleteWatcher_AC.

TidyHeap Director Changes:

Added new document type with more verbose descriptions of the options. TidyHeap Director is still compatible with the R13 version of TidyHeap.
