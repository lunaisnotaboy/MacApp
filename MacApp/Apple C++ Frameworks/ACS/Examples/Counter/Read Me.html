Win2MacCounter Sample

This is sample code to accompany Chapter 12 of "An Introduction to Macintosh Programming for Windows Programmers" available at http://developer.apple.com/macos/macoverview/.

This sample contains a series of six C++ sample programs used to illustrate how to write a simple Macintosh application. The samples use the Metrowerks PowerPlant applications framework, which ships as part of the CodeWarrior Integrated Development environment. (PowerPlant ships with a wide range of useful sample programs. We'll describe many of those in more detail below.) These samples illustrate many common applications features, including:

  1. Multiple document windows.
  2. Disk files for persistent data.
  3. Menu items for modifying the data.
  4. Buttons for modifying the data.
  5. Modal dialogs.
  6. Printing.
  7. Custom application and document icons.
  8. Customized "About this program…" dialog.

Change History

3/9/01

Updated to build with PowerPlant 2.1, CodeWarrior Pro 6, and Apple's Universal Interfaces 3.4 from the CarbonLib 1.2.5 GM SDK. Some minor changes to PowerPlant 2.1 were required to get it to compile. Some of the printing code in the Counter sample is #ifdef'ed out until it can be rewritten to work with PowerPlant's new printing architecture.

Made the application smaller by registering only the classes that are used. Made inclusion of the "GA" implementation conditional. Removed unused PowerPlant files from the project.

Integrated with the Apple Class Suites (ACS) and changed to use ACS TidyHeap and TemplateTempHandle.
