MacApp Release XV.I

 

Dear MacApp Developer,

Welcome to MacApp Release XV.I!

Archive

MacApp Release XV.I can be downloaded as one large disk image or as a series of a smaller segments.

MacApp can be downloaded via the MacApp web site.

Take a Look at Apple Class Suites

MacApp Release XV.I includes Apple Class Suites. Why do we mention this, something with which you believe you are familiar? Because the Apple Class Suites have been improved to such an extent that they are truly useful on their own, particularly within the Carbon environment. In fact, ACS can be downloaded as its own archive and used completely separately from MacApp.

ACS includes several new C++ classes that will help you effectively use Carbon's Core Foundation APIs, either on their own, or in conjunction with the C++ Standard Library classes and algorithms.

Download Only What You Need

If you are planning to use ACS in conjunction with MacApp then we recommend that you only download the MacApp release. However, if you do not plan to use MacApp then we recommend that you download only the ACS release.

MacApp Release XV.I builds on Mac OS X using Apple's Project Builder and Metrowerks' CodeWarrior Pro 6 and CodeWarrior Pro 7.
